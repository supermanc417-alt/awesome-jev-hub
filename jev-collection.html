一、先搞懂：Jev 到底是什么

一句话——它是「判断层」原语，不是「生成层」模型。理解了这一点，下面 58 个项目就全串起来了。

本质

TypeSafe 的 System One 模型

官方 slogan 是 "i. am. speed."。核心 API 原语只有三个：Choice（选）、Score（打分）、Noul（无意义/跳过）。输出带类型、可工程化，不像大模型那样吐自由文本。

架构角色

廉价低延迟的「判断路由层」

大模型负责「生成」，Jev 负责「判断与路由」。代价从「每次都调贵模型」降为「只在必要时调」。它观察状态→下判断→把执行交给大模型或底层系统。

为什么爆

便宜 + 够快 + 好接

① 便宜到可以每步都调；② 延迟低到能做实时决策（游戏/交易/无人机）；③ 带类型输出，工程好接；④ Agent 长上下文的「瘦身刚需」让它迅速成为标配。

怎么上手

三步进生态

  1. 去 typesafe.ai 拿 Jev API Key；
  2. 用 typesafe-mcp 或 jev-mcp 接进 Claude Code / Codex / 任意 MCP 客户端；
  3. 从 fast-jev-compaction / Winnow 体验上下文瘦身，立刻见效。
